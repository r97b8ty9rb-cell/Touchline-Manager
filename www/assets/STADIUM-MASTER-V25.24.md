# Stadium master artwork — V25.24

The approved new stadium artwork is `assets/stadium-master.png`.

It is also embedded directly in `index.html`, `www/index.html`, and the standalone HTML file so the game does not depend on an external image request. The source PNG is retained for future editing. The artwork itself has not been modified during integration.

The match renderer's fascia crop was adjusted from 61 to 64 logical pixels so the complete new advertising banner remains visible. The pitch/player rendering logic and stadium layout coordinates are otherwise retained.
